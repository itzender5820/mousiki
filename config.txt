# Local Music Paths
# Windows paths and ~ expansion both work; forward and backward slashes
# are both fine. Several paths are fine too (one line each). Edit them live
# in Settings -> PATH ("LOCAL PATH", or "+ new path" to add a line):
# committing a change rescans the library right away. Editing the file by
# hand still works -- do that while mousiki is closed, or rescan afterwards.
LocalMusicPath=C:\Users\you\Music
# LocalMusicPath=%USERPROFILE%\Music        (a second path would be a second line like this one, without the #)
 
# Playlists folder (optional, ONE folder). By default, saved playlists live in
# <first LocalMusicPath above>\playlists -- and if no LocalMusicPath is
# set at all, that silently falls back to %USERPROFILE%\.cache\mousiki\
# playlists. Only one folder is used (further PlaylistsPath lines are ignored);
# playlists are listed, loaded, saved and deleted there. Editable live in
# Settings -> PATH ("PLAYLIST PATH").
#PlaylistsPath=C:\Users\YOUR NAME!!!!!!\Music\playlists

# Playlist export folder (optional, ONE folder): where 'e' on the Saved
# Playlists tab of the playlist editor writes M3U8 / M3U files. Unset means
# the "export" folder inside the playlist folder. Editable live in Settings
# -> PATH ("PLAYLIST EXPORT PATH").
#PlaylistExportPath=C:\Users\YOUR NAME!!!!!!\Music\playlists\export

# Playlist import folder (optional, ONE folder): where 'i' on the Saved
# Playlists tab looks for M3U8 / M3U files. Unset means the "import" folder
# inside the playlist folder. The files stay there; a copy of each list lands
# in the "imported_lists" folder of the playlist folder. Editable live in
# Settings -> PATH ("PLAYLIST IMPORT PATH").
#PlaylistImportPath=C:\Users\YOUR NAME!!!!!!\Music\playlists\import

# Conversion export folder (optional, ONE folder): where the file conversion
# overlay (SHIFT+c) writes the converted files. Unset means the
# "conversion-export" folder inside the download folder. Editable live in
# Settings -> PATHS ("CONVERSION EXPORT PATH").
#ConversionExportPath=D:\Downloads\mousiki\conversion-export
 
# The audio book mode keeps its own look (colours, theme, elements, visualizations,
# borders, play mode, sound) in audiobook_config.txt next to this file; everything
# else (paths, hotkeys, the mode switches ...) is shared and lives here.

# Audio book folder (optional, ONE folder): the library of the audio book mode
# (SHIFT and + switches to it). Every folder in it that directly holds audio
# files is one book; a .cue file beside each book records where you last
# stopped listening (it also keeps the narrator, publisher and year; the
# music player's library leaves the files of this folder out; it may lie INSIDE a LocalMusicPath folder but may not be
# the same folder as one: that is a conflict). Editable live in Settings -> PATHS ("AUDIO BOOK PATH"),
# which is shown in every mode.
# In the audio book mode some hotkeys do other things (the keys stay the ones below): HKeyQueueOverlay (K) lists the
# auto-marks, bookmarks and notes of the books (HKeyQueueToPlaylist, CTRL+SHIFT+U, undoes a deletion there), HKeyFolderOverlay (F) / SHIFT+s is the library overlay, HKeyHistory (H) is the
# reading history (kept in reading_history.json next to history.json), HKeyLyricsTiming (ALT+L) sets chapter marks and
# cuts a file into chapters (the original stays as <name>.<ending>.mousiki-backup until you delete it there).
#AudioBookPath=D:\Audiobooks

# it downloads. Leaving it out means the built-in cache folder,
# %USERPROFILE%\.cache\mousiki, which is also what Settings shows in this
# field by default. The folder below is added to the local music paths
# automatically, so there is no need to repeat it as a LocalMusicPath= line.
# Editable live in Settings -> PATH ("DOWNLOAD PATH").
