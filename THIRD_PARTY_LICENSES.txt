Mousiki - third-party software
==============================

Mousiki itself is licensed under the Apache License 2.0 (see LICENSE).
This file lists the third-party code that is compiled into the mousiki and
fpcalc programs, with the licence texts their authors ask to be passed on,
followed by the tools that the installers and portable packages bundle and
the optional programs Mousiki can use. The sources of the compiled-in code
are in third_party/ of the source repository.

Compiled into mousiki
  - miniaudio 0.11.26 (David Reid) ............ public domain (Unlicense) or MIT-0
  - KISS FFT (Mark Borgerding) ................ BSD-3-Clause
  - miniz 3.1.2 (Rich Geldreich, RAD Game Tools, Valve Software) ... MIT
  - Roseus colour map (dofuuz/roseus) ......... CC0 1.0 (spectrogram colours)
  - stb_truetype 1.26 (Sean Barrett) .......... public domain (Unlicense) or MIT (karaoke: glyphs of Japanese / Chinese / Korean text from an installed font)
  - pypinyin pinyin table (mozillazg, hotoo) .. MIT (the Mandarin reading of each Chinese character, src/pinyin_table.inc: Latin letters display)
  - DejaVu Sans Mono glyph shapes (Bitstream, Inc.) ... Bitstream Vera licence (129 characters as 8 x 16 bitmaps, src/video_fx_ascii_font.inc: the ASCII video look)
Compiled into fpcalc (the AcoustID fingerprint helper in scripts/)
  - Chromaprint 1.6.2 (Lukas Lalinsky) ........ MIT, see the note in its section
  - KISS FFT, Chromaprint's own copy .......... BSD-3-Clause
Loaded at run time, if present
  - SDL2 (Sam Lantinga and contributors) ...... zlib licence
    Bundled as SDL2.dll in the Windows installer and portable zip; on Linux and
    macOS the system's SDL2 is used. Only the scope and spectrogram windows use it.
Artwork (braille pictures drawn after images from Pixabay)

    https://pixabay.com/videos/cat-piano-keys-musical-instrument-170617/
    Pixabay Content License (free for use, see https://pixabay.com/service/license-summary/).

Tools bundled with the installers and portable packages
==============================================================================

These are separate programs, downloaded unmodified from their projects when the
packages are built and listed again in THIRD-PARTY.txt inside each package:

  - FFmpeg (ffmpeg, ffprobe) ........ GPL-3.0 builds
      Windows: "essentials" build from https://www.gyan.dev/ffmpeg/builds/
      Linux portable zip: static build from https://johnvansickle.com/ffmpeg/
      Source code: https://ffmpeg.org (and the build pages above); the licence
      text is included as bin/ffmpeg-LICENSE.txt or bin/ffmpeg-GPLv3.txt
  - yt-dlp .......................... Unlicense - https://github.com/yt-dlp/yt-dlp
  - Python (embeddable, Windows) .... PSF License - https://www.python.org
  - Cascadia Mono (font, macOS app) . SIL Open Font License 1.1 - https://github.com/microsoft/cascadia-code
      Copyright (c) 2019 - Present, Microsoft Corporation, with Reserved Font Name Cascadia Code.
      Bundled unmodified in Mousiki.app (Contents/Resources/fonts/) together with its licence text
      (CascadiaCode-OFL.txt); the app copies the font into the user's ~/Library/Fonts. On Windows the font
      comes with Windows Terminal, on other systems the user installs it; Mousiki does not ship it there.
    (the Python scripts use only Python's standard library: no PyPI packages are bundled)

==============================================================================
Optional programs and libraries Mousiki can use (not bundled)
==============================================================================

  - pykakasi (kanji readings, pip) .......... GPL-3.0-or-later, called as a separate program (see the note at the end)
  - janome (Japanese word spacing, pip) ..... Apache-2.0, pure Python, called by scripts/kanji_reading.py; not bundled (installed only on request: the Windows installer task or setup.sh --with-kanji)
  - sidplayfp (C64 SID tunes) ............... GPL-2.0-or-later, run as a separate program
  - libopenmpt (tracker modules) ............ BSD-3-Clause, used through FFmpeg
  - libgme (game console music) ............. LGPL-2.1-or-later, used through FFmpeg
  - curl (radio station search) ............. curl licence (MIT-style), run as a program
  - ALSA / PulseAudio (Linux audio) ......... LGPL-2.1-or-later, loaded at run time by miniaudio
  - libdbus-1 (Linux media keys / MPRIS) .... AFL-2.1 or GPL-2.0-or-later, loaded at run time (dlopen); not linked
  - System Media Transport Controls (Windows) part of Windows, used through C++/WinRT (MIT, Windows SDK headers)
  - MediaPlayer framework (macOS) ........... part of macOS, used for Now Playing and the media keys

==============================================================================
Online services
==============================================================================

Mousiki talks to these services; their own terms of use apply to what they return:
YouTube, SoundCloud and Bandcamp (through yt-dlp), LRCLIB and lyrics-api.boidu.dev
(lyrics), AcoustID (fingerprint lookup), Radio Browser (radio station directory) and GitHub
(the public releases page, for the once-a-day new-version notice; UpdateCheck=false switches it off).
